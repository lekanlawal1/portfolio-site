Fine Print: an iOS app that checks contracts against Ontario law

Paste a lease, open a PDF, or photograph a job offer. Fine Print finds the clauses that matter and tells you, with the exact statute section, which ones Ontario law has already made void.

Swift 6SwiftUIApple Foundation Models Gemini APIVision OCRSwift Testing

Two-minute walkthrough, recorded in the iOS Simulator with real Gemini analysis: a problem lease, a scanned photo, and a contractor agreement.

The story

Tenants and new hires sign documents full of clauses Ontario law has already made void: "no pets" rules, damage deposits, non-competes. An AI model can read a contract in seconds, but one that confidently calls a legal clause illegal does real harm. So in Fine Print the AI only reads. It tags clauses from a closed list and must quote each one word for word. Ordinary, unit-tested code then checks that the quote exists, checks that the document's own wording supports the AI's label, and only then applies cited rules from the Residential Tenancies Act and the Employment Standards Act. Every rule was checked against the official statute text, and the app shows the date it was checked.

A 12-document test set built to break the system found the failure that mattered: both AI engines labelled "Pets are welcome" as a pet ban, and the rules then called it void. Quote checking couldn't catch it because the quote was real. A deterministic label check brought wrong legal verdicts to zero for every engine.

In the app

Key decisions I'd defend in an interview

  • The AI never issues a legal verdict. Verdicts come only from rule packs written as data, each with a citation, an official source link, and a verified date. A rule I couldn't verify against the statute doesn't ship.
  • Verify the quote, then verify the label. Quote checks catch invented clauses but not a real clause with the wrong label, which was the dangerous failure in testing.
  • Test capability, don't trust the flag. In the iOS Simulator Apple's on-device model reports "available" but every request fails, so the app picks its engine with a real test request at launch.
  • Gemini first, by measurement, with consent. Gemini found 100% of clauses versus 49% on-device, so it's preferred, but the app asks before any document leaves the phone.
  • Prompt changes get regression tests. A stricter prompt quietly broke overtime detection; the evaluation caught it and one clearer description fixed it.
