Football Stats Agent: Ask in English, Get an Answer You Can Check

Ask a football question in plain English and get the answer as a table, along with the database query that produced it, so you can check the working yourself.

What it does

You type a question the way you'd ask a friend, and it answers with a table. A few that work:

  • Who made the most tackles in the last 20 minutes of Premier League games in 2015/16?
  • Which strikers scored more goals than their chances were worth?
  • Who scored the most goals at the 2022 World Cup?

Under every answer there's a "Show the SQL" button. SQL is the database query behind the numbers, so anyone who reads SQL can see exactly how the answer was worked out. If a question is too vague ("who's the best striker?") it asks what you mean. If the data doesn't have the answer (wages, injuries, this season's games) it says so instead of making something up.

What's in the data

Most of it is StatsBomb's free match data, which logs every tackle, shot, foul and card with the minute it happened. It covers the whole 2015/16 season in England, Spain, Italy and France, the 2018 and 2022 World Cups, Euro 2020 and 2024, and Copa América 2024: 1,853 matches in all.

For more recent football there are season totals for the 2024/25 top five European leagues and the 2024 MLS season, from API-Football. I'm on their free plan, which allows 100 requests a day, so that part fills in a little more each day.

How it works

Your question goes to Google's Gemini model, which writes the query. Before anything runs, the query is checked twice: it may only read data, never change or delete it, and it can't reach anything outside the football tables. Then it runs in your own browser. The data sits on the website as files, and your browser downloads only the pieces the query needs. There's no database server to pay for or keep awake, so the page works instantly whenever someone opens it.

How I know the answers are right

I wrote 51 test questions and worked out the correct answer to each one by hand. Every time I change the AI's instructions, all of them run again automatically. The latest results:

22/22
questions answered correctly: same player and same number as my hand-checked answer (3 more wait on data still loading)
14/14
vague or unanswerable questions handled properly: it asked for detail, or said the data can't answer
12/12
attempts to break it stopped, like "ignore your instructions" or "delete the table"

The data gets checked too. For every one of the 1,853 matches, the goals in the event data have to add up to the official final score. That check found a match where one file said "Olympique de Marseille" and another said "Marseille", which made a 1-1 draw look like a 1-0.

What went wrong, and how I fixed it

The first test run got one answer wrong, and it looked completely believable. Asked which team scored the most goals in Serie A 2015/16, it said Napoli with 49. The real answer is Roma with 83. The model had counted home goals and away goals separately and never added them together, so 49 was only Napoli's home goals.

Instead of patching that one question, I changed how the data is stored: there's now a table with one row per team per game, so adding up a team's season is simple and hard to get wrong. The next run caught a similar mistake with assists, and I fixed it the same way. Later, someone asked which defenders kept clean sheets in the first half of home games, and it said it couldn't. The positions and half-time scores were in the raw data, just not where the AI could use them, so I added them. That question is now one of the tests. AI models don't give exactly the same answer every time, which is why the tests keep running.

My own expected goals model

Expected goals (xG) is the chance that a shot ends up in the net, based on where and how it was taken. I built my own from about 46,000 shots, using distance, angle, defenders in the way and the keeper's position. Each shot was scored by a version of the model that had never seen that match, so it couldn't cheat. It ranks shots almost as well as StatsBomb's professional model: 0.804 against 0.812 on the standard score, where 0.5 is a coin flip and 1.0 is perfect. You can ask the agent to use either one.

Limits

  • Nothing after the 2024/25 season. The free data plan stops there.
  • For 2024/25 there are season totals but no minute-by-minute events, so "tackles in the last 10 minutes in 2024/25" gets an honest no.
  • It runs on free plans, so each visitor gets about eight questions a minute.
