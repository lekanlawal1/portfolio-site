Sorted: Bank Support Messages, Routed Only When Two Models Agree

Type a message a bank customer might send and watch it go to one of seven support teams, or get held for a person. An AI and a plain model both read it, and code only sends it on when they agree.

The problem

A support desk spends minutes on every message just working out who should handle it. An AI can do that first pass in a second, but it can be confidently wrong, and its own "how sure am I" doesn't catch that. The first version of this project proved it: it filed complaints that mentioned money as billing questions at 95% confidence, and the confidence check never noticed.

How it works

The AI reads the message. Gemini returns a team, a priority, how sure it is and the words that decided it, in a fixed shape it can't step outside. Code checks that the quoted words are really in the message.

A plain model reads it too. A small text classifier trained on 10,003 labelled bank messages. It runs in your browser and never sees the AI's answer.

Code decides. A message goes straight to a team only when both pick the same team, the AI is at least 80% sure, and its quote checks out. Everything else goes to a person, with the reasons. The 80% bar was set before scoring, not tuned on the results.

The data

Banking77, a public set of 13,083 real customer messages to a bank, each labelled by people with one of 77 request types. I grouped those into seven teams a bank would actually have, and set priorities, before running any model. Nothing in the test set was written by me, so the scores can be checked.

What the first full run found

87.3%
of 770 test messages were sorted with no person involved
99.1%
of those reached the right team (6 wrong out of 672)
64
would have gone to the wrong team if the AI's confidence alone had been trusted

The AI's confidence is only loosely related to whether it's right: messages it rated 80 to 90% sure were right just 61% of the time. Most of its misses are on Transfers, where it often reads "top-up by bank transfer" as a Top-ups question. My grouping says Transfers; its reading is defensible.

The honest catch

The plain model on its own, sending only its 672 most confident messages, let 4 wrong ones through. On this data the AI doesn't make routing safer than a model trained on 10,000 labelled examples. What it adds is a quoted reason a person can check, and it works with no training data at all, which is the realistic case for a new inbox. The page shows both opinions and the right answer for every test message, and lets you filter to just the mistakes.
