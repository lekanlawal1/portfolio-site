About

I build tools for the boring problems that matter: the contract nobody reads closely, the PDF that has to be signed tonight, the warehouse count that doesn't match, the card fee nobody noticed.

One rule runs through all of it: nothing reaches you unchecked. Fine Print only flags a clause once code has confirmed it. The Gaffer writes its own SQL, then checks it and shows it, so every number can be verified. Sorted only routes a message when an AI and a plain model agree. Away from the keyboard I'm a Tottenham fan, which has taught me a lot about patience.

I'm looking for AI, data and BI roles in Canada, on a team that turns messy data into decisions people trust.
